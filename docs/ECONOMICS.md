# LEO Network Economics

## Status

Tokenomics are a research hypothesis. No production token decision has been made.

## Proof of Useful Observation

The network should reward useful physical observation and verification rather than computational waste.

Conceptual reward:

`quality × utility × novelty × independence × coverage × verifiability`

## Measurements required before token launch

`hardware cost → cost/hour → useful observations/day → verifications/day → data demand → data value → sustainable reward`

LEO is a candidate application/economic token. It does not automatically need to be the gas token.

Issuance, supply, inflation/deflation and burn mechanisms remain undecided.
